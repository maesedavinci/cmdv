CMDV Base

Estilos y componentes comunes para todos los sistemas del colegio. Cada sistema los importa con dos líneas y usa la versión que elija.

<link rel="stylesheet" href="https://maesedavinci.github.io/cmdv/base/1.0.0/cmdv.css">
<script src="https://maesedavinci.github.io/cmdv/base/1.0.0/cmdv.js"></script>
<!-- los componentes van dentro de un elemento con class="cx" -->

Colores

Colores de sistema de iOS más el verde institucional. Rojo = requiere acción, naranja = advertencia o pendiente, verde = listo o pagado, gris = sin efecto.

Control segmentado

Para cambiar de vista o de agrupación. Dos a cinco opciones.

CX.seg("miDiv", { valor: "estado", items: [{v:"estado", txt:"Estado"}, {v:"tipo", txt:"Tipo"}],
  onChange: v => pintar() });

Buscador y píldoras con contador

Filtros rápidos. El contador muestra cuántos quedan con ese filtro; el color indica la gravedad.

CX.buscador("busca", { placeholder: "Buscar persona", onInput: q => pintar() });
CX.pills("filtros", { valor: "todas", items: [{v:"todas", txt:"Todas", n:12}, {v:"sc", txt:"Sin cubrir", n:3, color:"red"}],
  onChange: v => pintar() });

Indicadores

Con onClick cada indicador también filtra la lista.

CX.kpis("kpis", [{v:"sc", color:"var(--cx-red)", titulo:"Sin cubrir", valor:"6 h", sub:"3 personas"}],
  { activo: filtro, onClick: v => filtrar(v) });

Lista agrupada

El patrón base: grupos con título, iniciales de color, un toque despliega el detalle y deslizar a la izquierda muestra acciones.

CX.lista("lista", { recordar: "aus", grupos: [{ titulo: "Requiere atención", filas: [{
  id: "AUS-1", nombre: "Navia Núñez Marcela", sub: "Licencia médica · lun 26 → vie 30",
  derecha: CX.tag("1 sin cubrir", "red"),
  detalle: () => "...html...",
  acciones: [{ txt: "Editar", icono: "✎", color: "blue", fn: id => editar(id) },
             { txt: "Anular", icono: "⊘", color: "red", fn: id => anular(id) }] }] }] });

Franja de períodos

Muestra un día de clases de un vistazo. Pasa el mouse sobre una celda para ver el detalle.

CX.franja({ periodos: 8, dias: [{ etiqueta: "mar 27", celdas: { 1: {estado:"pg", titulo:"..."}, 7: {estado:"cf"} } }] })
CX.leyendaFranja()   // pg verde · np gris · cf naranja · sc rojo · in azul
